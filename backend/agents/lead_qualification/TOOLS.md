# TOOLS DEFINITION FOR LEAD QUALIFICATION AGENT

## Danh sách Công cụ Hỗ trợ
1. `lead_intake_tool`: Tiếp nhận thông tin Lead từ API/Ads.
2. `conversation_analyzer`: Phân tích intent, trích xuất dữ liệu BANT.
3. `scoring_engine_tool`: Chấm điểm LeadScore và phân loại HOT/WARM/COLD.
4. `sales_handoff_builder`: Đóng gói bản tóm tắt chuyển giao Sales.
